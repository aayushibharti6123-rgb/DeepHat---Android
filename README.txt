DeepHat Toolkit — Android project starter

What is included:
- main.py: Kivy GUI version of the supplied command-line Python utilities.
- buildozer.spec: starter configuration for creating an Android APK with Buildozer.

Important:
- This ZIP is a project, not a compiled APK.
- Acode's Alpine terminal usually cannot run the full Buildozer Android build toolchain.
- Build the project on a Linux computer or a compatible Linux cloud environment with Buildozer and Android SDK/NDK.
- Network tools should only be used on systems you own or have permission to test.
- Test all features and review permissions before distributing the app.

Build on Linux (after installing Buildozer and its dependencies):
    buildozer android debug

The generated APK is usually placed under bin/.
